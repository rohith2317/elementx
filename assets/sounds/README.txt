Place your own audio files here to enable sound (all optional — the
game runs perfectly fine with no files present):

  menu_music.ogg   - looping background music for the main menu
  attack.wav       - basic punch / energy blast
  lightning.wav    - lightning ability
  fire.wav         - fire ability
  wind.wav         - wind ability
  shield.wav       - shield activation
  hit.wav          - impact / hit landed
  boss.wav         - boss intro / phase change
  victory.wav      - victory screen
  game_over.wav    - game over screen
  ultimate.wav     - ultimate attack
  heal.wav         - thumbs-up heal

Do not use copyrighted anime audio. Free, royalty-free SFX sources
such as freesound.org, opengameart.org, or Pixabay Audio work well.

SoundManager (audio/sound_manager.py) automatically skips any file
that isn't present, so you can add these incrementally.
